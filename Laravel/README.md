# 🛠️ IT Service Desk & Repair Management System
### ระบบแจ้งซ่อมและสนับสนุนงานไอที สำหรับองค์กร

ระบบเว็บแอปพลิเคชันสำหรับบริหารจัดการงานแจ้งซ่อมอุปกรณ์คอมพิวเตอร์และเทคโนโลยีสารสนเทศ (IT Support & Helpdesk) ออกแบบมาเพื่อให้ผู้ใช้งานทั่วไปสามารถแจ้งซ่อมและติดตามสถานะงานได้อย่างสะดวก รวดเร็ว พร้อมทั้งมีระบบหลังบ้านสำหรับเจ้าหน้าที่ IT ในการมอบหมายงาน อัปเดตสถานะ และบันทึกประวัติการแก้ไขปัญหาอย่างเป็นระบบ

---

## 🌟 ฟีเจอร์หลักของระบบ (Features)

### 1. ส่วนสำหรับผู้ใช้งานทั่วไป (Public Portal - ไม่ต้องล็อกอิน)
* **หน้าแรก (Home Portal):**
  * สรุปตัวเลขสถิติงานซ่อมในระบบแบบเรียลไทม์
  * กล่องค้นหาและตรวจสอบสถานะงานด่วน
  * การ์ดเลือกหมวดหมู่อุปกรณ์ที่ต้องการแจ้งซ่อม
  * แนะนำขั้นตอนการให้บริการ 4 ขั้นตอน
* **แบบฟอร์มแจ้งซ่อมออนไลน์ (New Ticket Form):**
  * เลือกหมวดหมู่อุปกรณ์ (คอมพิวเตอร์/โน้ตบุ๊ก, ปริ้นเตอร์, เน็ตเวิร์ก, ซอฟต์แวร์, บัญชีผู้ใช้, อุปกรณ์อื่น ๆ)
  * ระบุรหัสทรัพย์สิน / หมายเลขเครื่อง (Asset Tag)
  * ระบุสถานที่ตั้งอุปกรณ์ (อาคาร / ชั้น / ห้อง / แผนก)
  * เลือกระดับความเร่งด่วน 4 ระดับ (ต่ำ, ปานกลาง, สูง, เร่งด่วนมาก)
  * แนบรูปภาพปัญหาหรือภาพหน้าจอ Error (รองรับ JPG, PNG, WEBP)
* **ออกหมายเลขแจ้งซ่อมอัตโนมัติ (Ticket Generation):**
  * สร้างรหัส Ticket เฉพาะในรูปแบบ `IT-YYYYMMDD-XXX` พร้อมปุ่มคลิกคัดลอกรหัสทันที
* **ระบบติดตามสถานะงาน (Track Ticket):**
  * ค้นหาได้ทั้ง **หมายเลข Ticket** หรือ **เบอร์โทรศัพท์ของผู้แจ้ง**
  * แถบแสดงความคืบหน้า (Visual Progress Steps: แจ้งซ่อม ➔ รับเรื่อง ➔ กำลังดำเนินการ ➔ ซ่อมเสร็จสิ้น)
  * แสดงข้อมูลช่างผู้รับผิดชอบ, บันทึกแนวทางแก้ไขปัญหา, และประวัติการทำงาน (Timeline)

### 2. ส่วนสำหรับเจ้าหน้าที่ IT และผู้ดูแลระบบ (Admin & Technician Portal)
* **ระบบยืนยันตัวตน (Authentication):**
  * หน้าเข้าสู่ระบบสำหรับเจ้าหน้าที่ พร้อมปุ่มลัดสำหรับใส่บัญชีทดสอบ
* **ศูนย์จัดการงานแจ้งซ่อม (Admin Dashboard):**
  * การ์ด KPI สรุปสถานะงาน (งานทั้งหมด, รอดำเนินการ, กำลังซ่อม, รออะไหล่, ซ่อมเสร็จสิ้น)
  * ระบบตัวกรองข้อมูลขั้นสูง (Filter by Status, Priority, Category, Keyword Search)
  * ตารางแสดงรายการงานพร้อม Badge แสดงระดับความเร่งด่วนและสถานะอย่างชัดเจน
* **ระบบบริหารจัดการและปิดงาน (Ticket Management):**
  * มอบหมายงานให้ช่างผู้เชี่ยวชาญ (Assign Technician)
  * ปรับเปลี่ยนสถานะงาน 6 ระดับ (รอดำเนินการ, มอบหมายงานแล้ว, กำลังซ่อม, รออะไหล่, ปิดงาน, ยกเลิก)
  * บันทึกคำแนะนำหรือวิธีแก้ไขปัญหา (Resolution Notes) ให้ผู้แจ้งรับทราบ
  * บันทึกข้อความภายในทีม IT (Internal Audit Logs)
  * สิทธิ์เฉพาะผู้ดูแลระบบ (Admin) ในการลบรายการ

## 🛠️ เทคโนโลยีที่ใช้ในการพัฒนา (Tech Stack)

* **Framework:** Laravel 13 (PHP 8.4+)
* **Database:** SQLite (รองรับ MySQL / PostgreSQL)
* **View Engine:** Laravel Blade Templates
* **Styling & UI:** Modern Vanilla CSS Design System (Responsive, Modern Cards, Glassmorphism, Google Fonts: *Prompt* & *Plus Jakarta Sans*)
* **File Storage:** Laravel Storage Disk (Public Symlink)

---

## 🗄️ โครงสร้างฐานข้อมูล (Database Schema)

* **`users`**: ตารางข้อมูลผู้ใช้และเจ้าหน้าที่ IT (รองรับสิทธิ์ `admin`, `technician`)
* **`categories`**: ตารางหมวดหมู่อุปกรณ์ไอที (เช่น คอมพิวเตอร์, ปริ้นเตอร์, เน็ตเวิร์ก)
* **`repair_tickets`**: ตารางเก็บข้อมูลใบแจ้งซ่อม รายละเอียดปัญหา รหัสเครื่อง สถานที่ สถานะ และช่างผู้รับผิดชอบ
* **`ticket_histories`**: ตารางบันทึกประวัติความคืบหน้า (Timeline & Audit Trail)

## 🚀 การติดตั้งและเริ่มต้นใช้งาน (Installation)

### 1. ติดตั้ง Dependencies
```bash
composer install
```

### 2. ตั้งค่าไฟล์ Environment (.env)
```bash
cp .env.example .env
php artisan key:generate
```

### 3. รัน Database Migration และเพิ่มข้อมูลเริ่มต้น (Seeder)
คำสั่งนี้จะสร้างตารางและสร้างข้อมูลบัญชีทดสอบ รวมถึงรายการแจ้งซ่อมตัวอย่าง:
```bash
php artisan migrate --seed
```

### 4. สร้าง Symlink สำหรับไฟล์รูปภาพแนบ
```bash
php artisan storage:link
```

### 5. เริ่มต้นเซิร์ฟเวอร์ Local Dev
```bash
php artisan serve
```
จากนั้นเข้าใช้งานผ่านเว็บเบราว์เซอร์ที่: **http://127.0.0.1:8000**

## 🌐 รายการเส้นทางและหน้าจอหลัก (Route Map)

| เส้นทาง (URL) | Method | คำอธิบาย |
|---|---|---|
| `/` | `GET` | หน้าแรก Portal ต้อนรับ, สถิติ, และเลือกหมวดหมู่ |
| `/tickets/create` | `GET` | แบบฟอร์มกรอกข้อมูลแจ้งซ่อม IT |
| `/tickets` | `POST` | บันทึกข้อมูลคำขอแจ้งซ่อม |
| `/tickets/success/{code}` | `GET` | หน้ายืนยันและออกรหัส Ticket |
| `/tickets/track` | `GET` | หน้าค้นหาและติดตามสถานะงานซ่อม |
| `/login` | `GET/POST` | หน้าเข้าสู่ระบบเจ้าหน้าที่ IT |
| `/logout` | `POST` | ออกจากระบบ |
| `/admin/dashboard` | `GET` | แดชบอร์ดสรุปและกรองรายการงานทั้งหมด |
| `/admin/tickets/{id}` | `GET` | หน้าจอจัดการงาน, มอบหมายช่าง และปิดงาน |
| `/admin/tickets/{id}` | `PUT` | อัปเดตสถานะงานและบันทึกประวัติ |
| `/admin/tickets/{id}` | `DELETE` | ลบรายการแจ้งซ่อม (เฉพาะ Admin) |
